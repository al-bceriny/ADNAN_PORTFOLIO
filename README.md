# بورتفوليو عدنان بسيريني — Adnan Biseyrini Portfolio

موقع شخصي ثنائي اللغة (عربي / English) بتصميم داكن عصري، مبني بـ HTML و CSS و JavaScript فقط، دون أي أدوات بناء.

## هيكل الملفات

| الملف | الوظيفة |
|---|---|
| `data.js` | **كل المحتوى**: النبذة والمهارات والمشاريع والخبرات واللغات والروابط (بالعربية والإنجليزية) |
| `index.html` / `styles.css` / `script.js` | الموقع نفسه |
| `cv/cv.html` | قالب السيرة الذاتية، ويقرأ بياناته من `data.js` |
| `cv/build-cv.ps1` | يولّد ملفَّي السيرة الذاتية (العربي والإنجليزي) |
| `assets/cv/ar/ADNAN_BISEYRINI_CV.pdf` | السيرة الذاتية بالعربية، تُحمَّل عندما تكون لغة الموقع عربية |
| `assets/cv/en/ADNAN_BISEYRINI_CV.pdf` | السيرة الذاتية بالإنجليزية، تُحمَّل عندما تكون لغة الموقع إنجليزية |
| `assets/projects/` | صور المشاريع. أضف المسارات في حقل `images` للمشروع داخل `data.js`؛ الصورة الأولى غلاف، والضغط عليها يفتح معرض الصور |

## التشغيل محلياً

```bash
npx http-server -p 5500
```

ثم افتح http://localhost:5500

## تحديث السيرة الذاتية

بعد تعديل `data.js`، شغّل الخادم المحلي أولاً ثم:

```bash
powershell -ExecutionPolicy Bypass -File cv/build-cv.ps1
```

## النشر

ارفع محتويات المجلد كما هي إلى الاستضافة (أو GitHub Pages أو Netlify). لا حاجة لرفع مجلد `.claude`.

## نموذج التواصل

النموذج يفتح تطبيق البريد لدى الزائر. لاستقبال الرسائل مباشرة استخدم [Formspree](https://formspree.io) وعدّل معالج `submit` في `script.js`.
